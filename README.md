# WireGuard Widget

Лёгкая утилита (C# WinForms, .NET Framework 4.8) для быстрой проверки и переключения конфигураций WireGuard for Windows.

## Сборка

```
dotnet build WireGuardWidget.sln -c Release
```

Готовый файл: `WireGuardWidget\bin\Release\WireGuardWidget.exe` — можно скопировать в любую папку.
Проект также открывается в Visual Studio 2019+.

## Как пользоваться

- Утилита запрашивает права администратора: без них Windows не даёт управлять службами туннелей.
- Папка WireGuard ищется автоматически (`Program Files\WireGuard` или путь службы `WireGuardManager`), её можно поменять в настройках (⚙).
- Кнопка **+** (или перетаскивание `.conf` в окно) добавляет конфигурацию: файл сохраняется в `Data\Configurations` как `имя.conf`,
  а служба WireGuard сама зашифрует его в `имя.conf.dpapi` — как при импорте через её собственный интерфейс.
  Имя туннеля — латиница, цифры и `_ = + . -`, до 32 символов.
- Тема оформления (тёмная / светлая / как в Windows) — в настройках (⚙).
- Клик по эмодзи в строке — выбор иконки (вкладки «Эмодзи» и «Флаги»); строки можно перетаскивать мышью — порядок задаёт номер хоткея.
  Цветных флагов в шрифтах Windows нет, поэтому около 60 флагов утилита рисует сама; любой другой флаг, введённый вручную, будет показан буквами.
- **Ctrl+1…9** — подключить конфигурацию с этим номером, повторное нажатие — отключить её (во время подключения — отменить). **Ctrl+0** — отключить все.
  Модификатор меняется в настройках (Ctrl / Ctrl+Alt / Ctrl+Shift / Alt+Shift / выкл).
- «Только одно подключение» — перед подключением остальные туннели отключаются.
- Кнопка ⧉ в шапке переключает на оверлей: перетаскивается мышью, двойной клик — обратно к окну, правый клик — меню (размер, прозрачность).
- Крестик прячет окно в трей. Выход — через меню значка в трее. Туннели при выходе не отключаются.

## Как это работает

- Подключение: `wireguard.exe /installtunnelservice <Data\Configurations\имя.conf.dpapi>`, отключение: `wireguard.exe /uninstalltunnelservice <имя>` — то же, что делает GUI WireGuard.
- Статус: состояние службы `WireGuardTunnel$<имя>` (опрос раз в 2 с).
- После подключения: ждём, пока служба перейдёт в Running и не упадёт следом; затем (если включено) ждём handshake через `wg.exe show <имя> latest-handshakes`,
  отправляя ping на адрес из AllowedIPs, чтобы спровоцировать handshake. При неудаче — до 3 попыток, затем уведомление в трее.

## Файлы рядом с exe

- `WireGuardWidget.json` — все настройки (порядок и иконки конфигураций, хоткеи, положение окна и оверлея).
- `WireGuardWidget.log` — журнал ошибок (появляется только при ошибках).

Автозапуск (флажок в настройках) создаёт задание `WireGuardWidget` в Планировщике заданий — так утилита стартует с правами администратора без запроса UAC.

## Иконка

`WireGuardWidget\app.ico` генерируется программой `tools\IconGenerator` (векторный рисунок в коде):

```
dotnet run --project tools\IconGenerator -c Release -- WireGuardWidget\app.ico preview.png
```
